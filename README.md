# RaruEarnings

Site feito para gerenciamento pessoal de ganhos, débitos e ordens relacionadas a diferentes tarefas na área de prótese dentária, com objetivo de obter maior controle sobre trabalhos efetuados e seus respectivos valores.

---

## 🎯 Funcionalidades

- Cadastro de clientes e tarefas padrões
- Controle de ordens de serviço
- Cálculo de ganhos e débitos conforme intervalo de data selecionada
